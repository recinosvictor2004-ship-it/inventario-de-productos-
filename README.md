# Inventario de Tienda en Python

Aplicación de consola desarrollada en Python para gestionar el inventario de una tienda pequeña.  
Incluye manejo de productos, actualización de cantidades, eliminación y cálculo del valor total del inventario.

## 🧰 Funcionalidades
- Agregar producto
- Listar productos
- Actualizar cantidad
- Eliminar producto
- Calcular valor total del inventario
- Menú interactivo por consola

## 🛠 Tecnologías utilizadas
- Python 3
- Git
- GitHub
- Ramas y Conventional Commits

## ▶️ Ejecución
```bash
python3 main.py
